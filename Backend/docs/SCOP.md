# 🌱 Plant Laboratory Management System (PLMS)

### 🎯 Objective

A system to manage plant resources, chemical inventory, lab equipment, and user contributions with proper tracking, security, and reporting.

---

# 📦 Module 1: Plant Management

**Features:**

* Manage **Species, Variety, Sample** with name, code, image, description
* **Stock Management**: track all changes via transactions (IN / OUT / ADJUST)
* **Ownership & Contribution**: each sample linked to user
* Display detailed info per species, variety, and sample

**Benefits:**

* Prevents manual quantity errors
* Tracks contributions for academic purposes

---

# 🧪 Module 2: Chemical Management

**Features:**

* CRUD chemical master data: name, code, safety info, image
* **Batch-based tracking**: quantity, expiry date, supplier
* **Usage tracking**: log who used how much, when, and purpose
* **Expiry alerts**: notifications for near-expiry and expired chemicals

**Benefits:**

* Ensures lab safety
* Full traceability of chemical usage

---

# 🛠 Module 3: Equipment Management

**Features:**

* CRUD equipment info: name, code, serial number, manufacturer, status
* **Borrow & Return Workflow**: approval system, automatic status updates
* **Maintenance Tracking**: repair history, technician info, next service date

**Benefits:**

* Efficient asset management
* Prevents loss/damage
* Supports maintenance scheduling

---

# 🔐 Module 4: Authentication & Authorization

**Features:**

* **JWT-based login** with encrypted passwords
* **Role-Based Access Control (RBAC)**:

  * Admin: full access
  * Lab Manager: manage lab resources
  * Student: add/update data only
* **Audit logging**: track all critical actions

**Benefits:**

* Secure system access
* Clear permission management
* Activity history for accountability

---

# 👤 Module 5: User Profile

**Features:**

* Personal profile page
* Manage achievements & document links
* Track contributions (samples added, chemicals added)
* View overall activity summary

**Benefits:**

* Encourages student accountability
* Easy tracking of individual contributions

---

# 📊 Dashboard & Reporting

**Features:**

* Dashboard: overview of plants, chemicals, equipment, and activities
* Reports: inventory, chemical usage, expired items, borrowed equipment, user activity
* Export to PDF / Excel

**Benefits:**

* Quick lab overview
* Professional reporting for management & research

---

* Batch-based chemical expiry tracking
* Borrow/Return workflow for equipment
* Role-based security and audit logs
* Dashboard & reporting for quick insights
